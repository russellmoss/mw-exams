### Branch 6.4 lock: one fork per pair, not five points on a ladder
This is NOT the classic F6a sweetness ladder (Branches 6.1-6.3, one flight plotting five wines across a single shared RS-x-alcohol axis). It is Branch 6.4: four independent pairs, each anchored on a single named production-method fork within a shared origin. Per `p3_family_tree_pack.md` Branch 6.4, the canonical fork families to pre-load are:
- **Dosage/style level within the same base wine and appellation** — Champagne.
- **Oxidative cask ageing vs reductive/bottle-then-filtered ageing** — Port (and by extension Sherry, Madeira).
- **Classified/1er Cru vs unclassified/second-label within the same botrytis appellation** — Sauternes-Barsac.
- **Dry (Trocken/GG-tier) vs Prädikat-sweet (Spätlese), one grower, two vineyards, same region** — German Prädikat estates (Nahe, Mosel, Rheingau all plausible; Nahe is the live 2026 instance).

## Rule-outs
- **A second sparkling pair**: ruled out — Q1 already owns that territory in full.
- **Eight dry, still, unfortified wines**: inconsistent with 48 marks dedicated to ABV/RS as legible, discriminable facts; dry table wines cluster too tightly to justify that weighting.
- **Four totally unrelated fortified/botrytis families with no German Prädikat representation**: unlikely given the numeric marks demand the widest possible ABV/RS spread, which only the German ladder reliably supplies at the low-alcohol end.
- **Jerez displacing Douro**: both are textbook fortified same-region forks, but only one slot is available for "classic Iberian fortified" — Douro's Tawny/LBV contrast is at least as well precedented in the P3 corpus (2018 P3 Q1) and was the actual choice.

## The IMW's likely intent
Testing (1) precise origin ID within specialty categories once geography is held constant within each pair; (2) the ability to explain a contrasting production METHOD that co-exists inside a single appellation — the money skill (dosage level, cask-vs-bottle ageing, classified-vs-unclassified selection/barrel regime, dry-vs-Prädikat picking decision); (3) numeric fluency translating aroma/palate impression into concrete ABV%/RS g/L estimates, worth a full quarter of the marks; (4) quality/hierarchy literacy within one region (Reserva-adjacent tiers, cru classifications, VDP site rankings) rather than across regions.
